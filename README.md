# PortWin — downloads

**Windows games and apps on your Mac. No Windows needed.**

PortWin runs Windows programs on Apple silicon Macs through Wine — no virtual machine, no Windows license.
One-click recipes for Steam, Epic Games, Skyrim and more, Windows XP-era software, crackle-free sound and a built-in Wine engine.

👉 **[Download the latest version](https://github.com/maestroowner-pixel/portwin-releases/releases/latest)** · Website: **[portwin.kuka-lab.com](https://portwin.kuka-lab.com)**

## Requirements

- Mac with Apple silicon (M1 or later)
- macOS 14 Sonoma or later
- About 1.1 GB of disk space, plus your games and programs

## Install

1. Download `PortWin-<version>.dmg` from [Releases](https://github.com/maestroowner-pixel/portwin-releases/releases/latest).
2. Open it and drag **PortWin** to **Applications**.
3. Launch PortWin — the app is signed and notarized by Apple, so it opens without warnings.
